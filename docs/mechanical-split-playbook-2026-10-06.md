# Mechanical Split Playbook (2026-10-06)

本手册把 2026-10-06 机械拆分系列（#220–#229，runtime 客户端三接缝、
WordPress AI 连接器按类拆分与去重加固、媒体传输五接缝、描述符规则
单源化）反复验证过的流程与踩坑固化为规范。目标是：下一次拆分不再
依赖个人记忆，按本手册执行即可复现同等质量。

## 适用范围

适用于"把一个过宽类中的内聚方法群搬移到新文件"的重构：纯函数守卫、
静态校验器、投影构建器、按类拆文件。不适用于语义性重构（错误粒度、
检查顺序、谓词真值表改变的工作，如 #229 的描述符去重需逐谓词设计，
不可套用机械流程）。低收益拆分（如 settings-page 披露标记合并，实测
仅约 40–70 行）应先测量再立项。

## 七步流程

1. **盘点**：目标文件全方法/常量清单（行号、可见性、静态与否）；逐
   方法标注 `$this->` 实例依赖与环境读取（config、`home_url()`、时钟、
   `function_exists` 预检）；列出共享常量与共享助手的双侧使用点。
   只有引用面盘全，归属决策才有依据。
2. **方向文档先行**：接缝、顺序、预期行数、已知坑先落
   `docs/cloud-addon-complexity-budget.md`（独立 docs PR，参照 #218/#223），
   再逐步执行。每步一个独立 PR，全程可 revert。
3. **脚本化机械搬移**：用一次性 Python 脚本按"docblock 回溯 + 签名行
   匹配 + 同缩进闭合花括号"定位方法块，逐字搬移；对缩进异常的历史
   行用 `^\t+` 容忍匹配并以声明行的实际缩进找闭合。改写仅限两类：
   可见性/静态化、`$this->helper(` → `self::helper(`。脚本内对每处
   替换断言命中次数，失败即中止不写盘。
4. **参数化唯非纯点**：实例状态与环境读取改为调用点注入参数（参照
   connector 校验器注入 site_id/site_url/version、诊断投影注入 config
   快照与 is_configured）。错误消息与判定逐字保留在守卫内。
5. **接线五件套**：bootstrap require（依赖先于消费者）、tests/helpers.php
   的 `maca_load_addon_classes()`、release-manifest.txt（字母序）、直接
   require 捆包文件的行为测试补卫星文件 require、bootstrap 门面函数与
   测试调用点改指新类。
6. **失败驱动契约重定向**：跑 `composer run test:contracts`，对失败断言
   按子串所有权改指新源变量。用 PHP 求值器脚本自动重定向（`eval` 解析
   字面量后在各源中定位），**负向禁令一并处理**——指向瘦身后主文件的
   禁令会空转，应改扫合并 haystack（见 #224 修补）。棘轮改多文件并连
   同文档清单一起更新；调升必须记录理由（参照 #229）。
7. **门禁与分诊**：`test:all`、`git diff --check`、`i18n:refresh` +
   `i18n:check`、`stan`（基线重指向，只缩不涨；防御性再验证族不清零）、
   `package:release` + `package:verify`、`smoke:playground`（bootstrap
   变更必跑）、`ocr review`。审查发现分诊：拆分引入的缺陷必须修，
   搬移前已存在的行为记录后另行处理（参照 #224 记录四项 → #226 落地）。
   发布后回看完整 check rollup——合并本身不是证据。

## 关键规则

- **逐文件守卫**：拆分后每个新文件的类定义守卫必须按自身依赖编写；
  不得沿用原整块条件。`! class_exists( '入口类' )` 复用会导致第二个
  文件起跳过自身定义（#224 首版踩中）。版本偏斜必须与拆分前同样
  fail-closed（参照 provider 恢复联合三条件）。
- **共享成员的归属**：共享常量与标量助手放最低层卫星类公开、其余跨类
  引用；方向必须无环：编排 → 校验/投影卫星，仅设置绑定工厂（如
  `verified_client`）允许回调。
- **POT 纪律**：任何改变源文件行号的 amend（哪怕一行常量上移）之后
  必须重跑 `i18n:refresh` 再推送——#228 首推因此挂掉必需检查
  Release static gates。
- **验证管道纪律**：`cmd | grep fail || echo PASS` 会把致命错误吞成
  通过（本会话踩中）；判定一律看退出码，日志另存文件再查。

## 踩坑清单（工具层）

- docblock 回溯用 `strip()` 比较 `*/`，不要 `rstrip()` 比较带制表符形态。
- ocr 的 JSON 输出可能带前置工具噪音行，解析前先截取首个 `{`。
- zsh 中裸 `===` 会触发等号展开报错，避免用作分隔符。
- GitHub 直连在本机不通，git/gh 需带 `https_proxy=http://127.0.0.1:12000`；
  `composer pr:publish` 需 `COMPOSER_PROCESS_TIMEOUT=900`。
- Playground 偶发"smoke route 未就绪"服务早退多为网络瞬断，带代理重试
  一次再判定。

## 完成后的账面纪律

复杂度棘轮、基线、POT、manifest 与文档清单在同一个 PR 内同步；暂时
不做的事项（机会主义跨文件重复、低收益合并）在文档中显式标注"不指派
PR"，避免下次盘点时被误认为欠账。
