| 严重程度 | 具体问题 | 根本原因 | 后续做法 |

### 技术归档规则

- 重要事实先做完整清单，再做信息减法；重要性与使用频率分别判断。低频的重要
  恢复入口可以下沉，但异常影响、账号归属、套餐身份和状态时效不能消失。
- 默认、展开、失败、恢复是独立验收面。检查 DOM 中“存在”之外，还要检查
  实际可见、关闭祖先、锚点可达、窄屏尺寸与同次刷新的一致性。
- 数据未知、处理中、确认成功必须区分。无缓存不能称为保留旧数据；待处理不能
  计入完成；隔离模拟不能代替真实 Cloud 往返。
- AI 审查逐条复核事实。WordPress post/page/attachment 共用全局 post ID，不能
  采纳“不同类型 ID 碰撞”的错误推断。`add_query_arg()` 的新增查询值需调用者编码，
  不因泛化的双重编码建议破坏 `#ID` 与中文上下文。
- 有范围 nonce、管理员权限、当前站点作用域和有界解析的恢复操作不再要求输入英文
  确认词；这项新手体验决策不等于取消授权。排除保留数量确认和无 JS 显式确认。
- 按平台 2026-11-03 生效规则，使用本机配置的 Qwen／DeepSeek 审查，不等待已停用
  的云端 OCR。完整变更超过单次 220,000 字符时，按连续提交范围拆审；每段保留
  完整 diff 哈希、base/head、模型、全部发现及处理结论，覆盖范围不得有缺口。
  MO 二进制另以语言、打包与运行页面检查验证，不声称模型读过其内容。
