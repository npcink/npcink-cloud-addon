# Reversible Cloud Feature Pauses v1

Status: development candidate, 2026-10-19. No plugin distribution or production
deployment is implied.

The source availability policy in `Npcink_Cloud_Discoverability_Pause` now also
pauses Cloud inspection/site analysis, article audio, advanced media derivative
jobs, batch derivative plans, governance audits and new optimization plans.
Exact ability, execution-kind, profile and contract markers are checked, never
article-body keywords. All named transports converge on the pre-signing guard;
derivative dispatch additionally stops before source uploads. Runtime retry
returns `cloud_feature_paused` with HTTP 409 and `retryable=false`.

WordPress options, consent, credentials and old records are not deleted or
rewritten. Historical run/result reads, existing artifact downloads/ACK and
ordinary WordPress AI text, image, ALT, Site Knowledge, search and opt-in
monitoring remain supported. The entitlement projection marks inspection
unavailable even when a retained cached entitlement describes the old service.

Implementation and public method signatures are retained. They do not grant
availability. Restoration requires a reviewed source change across Cloud,
Addon and the corresponding Toolbox entrypoints, plus current consumer tests;
reconnecting or refreshing caches cannot enable a paused feature.

Verification includes the default release policy with zero outbound calls,
retained implementation fixtures, ordinary formatting/connector regressions and
full PHP/static/boundary checks. Private reflection overrides exist only in
test fixtures; no public switch, setting or registry is added.

The coordinated scope and evidence live in Cloud's
`docs/reversible-feature-pauses-v1.md`. Restore each corresponding batch commit
only after checking dependencies against the current installed host versions.
