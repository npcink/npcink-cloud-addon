# Addon 安装引导与知识库读取反馈候选

状态：2026-10-17，本地 development 候选；不是已发布的 Addon 0.4.1。

本轮独立工作区从 `3e650d1` 建立，未改站点 symlink、共享根目录、历史内容
恢复、change bridge、游标、Cron、签名传输或内容写入。不使用付费 OCR/Provider。

- 已连接后，在概览显示缺失官方 AI 插件的提示，链接到 WordPress 自有的官方
  `ai` 插件安装页；已安装未启用时链接插件启用页；已启用后隐藏缺失提示。
  不自动安装/启用、不访问 Cloud、不在页面加载时生成内容。
- 知识库失败反馈区分未验证、关闭、刷新中、Cloud 返回不完整及请求失败。
  仅传递经过格式约束的错误码，丢弃远端错误正文；不把读取失败显示为 0 用量。
  AJAX 仍要求管理员权限和 nonce，使用相同显示投影。
- 中英文目录、MO 与旧语言包的中文后备映射同步更新。

零付费验证：`composer run test:all`、PHPStan、WordPress.org guard、JS 检查和
POT freshness 通过；定向行为覆盖安装指引、启用后隐藏、失败码、未返回状态
及不暴露错误正文。真实 PHP 渲染器的模拟页面已在 PC 浏览器检查；这不是
真实 WordPress/Cloud 的 Tier C 证据。未改 bootstrap、默认凭据、公开 connector
API 或兼容基线，因此 Playground 不适用。未做发布打包、合并、tag 或站点更新。

验收顺序：隔离站点分别检查未安装、已安装未启用、已启用三种状态；确认按钮
目标由 WordPress 持有，刷新页面不产生模型请求。模拟知识库正常、刷新中、
返回不完整、HTTP 503 等结果，确认文案和错误码与实际相符，不保留虚假的
“刷新成功”。随后再按 Cloud 仓库 `docs/runtime-configuration-acceptance-2026-10-17.md`
进行配套版本和最小真实写作验收；生产必须等另行批准的发布，不能直接覆盖
正在使用的插件目录。

反馈：北京时间、WordPress/Addon/官方 AI 版本、站点、当前步骤、操作、提示
原文、安全错误码、run/trace（未显示则注明）、脱敏截图；不得提供密钥和 Cookie。
回退为撤销本候选提交，没有生产配置或数据库迁移需要回退。
